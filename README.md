# 🛸 Space Invaders

## 🎮 Sobre o projeto

**Space Invaders** é um jogo arcade 2D inspirado nos clássicos jogos de fliperama.

No jogo, o jogador controla uma nave espacial equipada com um sistema de disparos e deve enfrentar diferentes animais que aparecem como inimigos durante as fases.

O projeto combina uma estética retrô com uma experiência simples e dinâmica, baseada em jogos clássicos de arcade, onde o objetivo principal é sobreviver, derrotar os inimigos e alcançar a maior pontuação possível.

## 🕹️ Objetivo do jogo

O objetivo é controlar a nave espacial e eliminar os animais inimigos antes que eles consigam atingir a área do jogador.

Durante a partida, o jogador deverá:

* Controlar a nave;
* Atirar contra os inimigos;
* Evitar ataques e colisões;
* Eliminar os animais;
* Acumular pontos;
* Gerenciar suas vidas;
* Avançar pelas fases;
* Buscar a maior pontuação possível.

A dificuldade aumenta progressivamente, fazendo com que o jogador precise reagir cada vez mais rápido.

## 🚀 Gameplay

A partida começa com o jogador controlando uma nave na parte inferior da tela.

Os animais inimigos aparecem na parte superior e se movimentam pelo cenário. O jogador deve utilizar os disparos da nave para eliminá-los.

Conforme os inimigos são derrotados, novos grupos aparecem e a dificuldade aumenta.

O jogo possui diferentes fases, permitindo que a velocidade, quantidade e comportamento dos inimigos sejam modificados progressivamente.

## 🐾 Inimigos

Os principais adversários do jogo são animais representados de maneira estilizada, mantendo a temática arcade.

Cada grupo de inimigos pode possuir características diferentes, como:

* Velocidade;
* Resistência;
* Pontuação;
* Padrão de movimento;
* Comportamento durante o ataque.

A variedade de inimigos torna cada fase mais desafiadora.

## 🔫 Sistema de disparos

A nave possui um sistema de disparos utilizado para eliminar os inimigos.

Os tiros possuem efeitos sonoros para aumentar a sensação de interação durante a partida.

O jogador deverá utilizar os disparos de maneira estratégica para conseguir eliminar os inimigos enquanto evita perder vidas.

## ❤️ Sistema de vidas

O jogador começa a partida com uma quantidade limitada de vidas.

Quando a nave é atingida ou ocorre uma colisão que provoque a perda de uma vida, o contador é atualizado.

Ao perder todas as vidas, a partida é encerrada e o jogador recebe a opção de iniciar uma nova partida.

## 🏆 Sistema de pontuação

Cada inimigo eliminado gera pontos para o jogador.

A pontuação é exibida durante toda a partida, permitindo acompanhar o desempenho.

Inimigos mais difíceis podem oferecer uma quantidade maior de pontos, incentivando o jogador a avançar pelas fases e buscar pontuações mais altas.

## 🌌 Fases

O jogo é dividido em diferentes fases.

A cada nova fase, a dificuldade aumenta gradualmente, podendo ocorrer alterações como:

* Maior quantidade de inimigos;
* Maior velocidade;
* Novos tipos de animais;
* Novos padrões de movimentação;
* Maior dificuldade para evitar ataques.

O objetivo é fazer com que o jogador permaneça constantemente desafiado.

## 🎯 Game Over

Quando o jogador perde todas as vidas, a partida chega ao fim.

Uma tela de encerramento apresenta a situação da partida e permite ao jogador escolher entre iniciar novamente ou terminar o jogo.

A pontuação alcançada durante a partida também pode ser apresentada ao jogador.

## 🪟 Interface

A interface foi projetada para manter uma aparência simples e semelhante aos jogos arcade clássicos.

A tela principal apresenta:

* Nome do jogo;
* Pontuação atual;
* Quantidade de vidas;
* Área principal da partida;
* Nave do jogador;
* Animais inimigos;
* Disparos;
* Elementos visuais das fases.

A proposta visual utiliza uma estética retrô, com destaque para o cenário escuro e os elementos do jogo.

## 🔊 Áudio

O jogo possui efeitos sonoros para tornar a experiência mais dinâmica.

Entre os efeitos planejados estão:

* Disparo da nave;
* Acerto de inimigos;
* Destruição de inimigos;
* Perda de vida;
* Final da partida;
* Mudança de fase.

Os efeitos sonoros complementam a estética arcade do projeto.

## 🛠️ Tecnologias utilizadas

O projeto é desenvolvido utilizando tecnologias web:

* **HTML5** — estrutura da aplicação;
* **CSS3** — interface e elementos visuais;
* **JavaScript** — lógica e funcionamento do jogo;
* **Canvas API** — renderização dos elementos da partida;
* **JavaScript Audio API/HTML Audio** — reprodução dos efeitos sonoros.

## 💻 Plataforma

O jogo foi desenvolvido para ser executado diretamente em navegadores modernos.

Não é necessário instalar um programa específico para jogar. Basta acessar a página do jogo através de um navegador compatível com as tecnologias utilizadas.

O jogo utiliza:

* Interface minimalista;

## 📈 Progressão

A progressão do jogo ocorre através das fases.

Quanto mais o jogador avança:

1. Os inimigos ficam mais numerosos;
2. Os inimigos ficam mais rápidos;
3. Novos tipos de inimigos aparecem;
4. Os padrões de movimentação se tornam mais difíceis;
5. A pontuação necessária para alcançar novos recordes aumenta.

Dessa maneira, o jogo mantém uma dificuldade progressiva e incentiva o jogador a continuar jogando.

## 🏅 Recorde

O jogo poderá registrar a maior pontuação alcançada pelo jogador.

O sistema de recorde permite que diferentes partidas sejam comparadas, incentivando o jogador a tentar superar sua própria pontuação.

## 📂 Organização do projeto

O projeto é organizado separando os principais elementos da aplicação:

Essa organização facilita a manutenção e evolução do projeto.
